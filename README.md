# HR-Analytics-Dashboard


HR Analytics Dashboard

This project is developed as part of my internship at Syntecxhub
📌 Project Overview

The HR Analytics Dashboard helps analyze employee attrition and workforce trends using interactive visualizations in Power BI.

📊 Dashboard Insights
Overall Employee Count
Attrition Count & Rate
Average Salary & Age
Attrition by Education
Attrition by Gender
Attrition by Salary Slab
Attrition by Job Role
Attrition by Years at Company

🛠 Tools & Technologies
Power BI
Data Cleaning
Data Visualization
HR Analytics


🎯 Objective
To identify key factors affecting employee attrition and provide actionable business insights through interactive dashboards.
